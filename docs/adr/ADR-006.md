# ADR-006 — Local setup UI (offline web)

## Status

Accepted — Sprint 43 (`1.27.0`)

## Context

Non-technical users on corporate Windows struggle with CLI-only setup for Kiro MCP.
PyPI/CLI remain for maintainers; day-to-day operators need a guided local UI.

Earlier backlog marked web UI as Won't for MVP (PB-902). Adoption reality on
locked-down Windows reverses that for a **local-only** setup surface.

## Decision

Ship `dce ui`: a **localhost-only** HTTP wizard (stdlib `http.server`) that:

1. Selects/creates a workspace (`init`)
2. Indexes sources
3. Shows doctor / facets status
4. Generates Kiro MCP JSON to copy
5. Smoke-tests `build_context`

No cloud, no auth, bind `127.0.0.1` only. No new runtime dependencies.

## Consequences

- Portable `dce.exe` must bundle `dce.interfaces.web` + static HTML.
- PB-902 narrowed: **no multi-user/cloud UI**; local setup UI is in scope.
- CLI remains supported; UI is a thin facade over the same use cases.
